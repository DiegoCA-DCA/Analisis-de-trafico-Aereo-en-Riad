# Análisis de Tráfico Aéreo en Riad (RUH)  
## Dashboard de Vuelos con Python (Pandas + Matplotlib)

**Análisis exploratorio y visualización** de datos reales de vuelos en el Aeropuerto Internacional Rey Khalid (RUH), Riad, Arabia Saudita.
## Objetivo del Proyecto
Realizar un **EDA completo** y construir un **dashboard profesional** con 4 KPIs clave:
1. Top 8 aerolíneas por frecuencia  
2. Distribución por estado del vuelo  
3. Patrón horario de despegues (UTC)  
4. Evolución diaria de operaciones

| Herramienta | Uso |
